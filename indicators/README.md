# 平均足スムーズド (Heiken Ashi Smoothed) オーバーレイ

通常のローソク足チャートに、平均足スムーズドを重ねて表示するインジケーターです。

| プラットフォーム | ファイル |
| --- | --- |
| MetaTrader 5 | `mt5/HeikenAshiSmoothedOverlay.mq5` |
| TradingView | `tradingview/HeikenAshiSmoothedOverlay.pine` |

## 計算方法 (MT5・TradingView 共通)

1. 価格の始値・高値・安値・終値を 1段目の移動平均で平滑化（初期値: SMMA 6）
2. 平滑化した値から平均足を計算
   - 終値 = (O + H + L + C) / 4
   - 始値 = (前の足の平均足始値 + 前の足の平均足終値) / 2
3. 平均足の 4本値を 2段目の移動平均でさらに平滑化（初期値: LWMA/WMA 2）

初期値は MT4 でよく使われている「Heiken Ashi Smoothed」と同じ設定です。

## MT5 への導入

1. MT5 で「ファイル」→「データフォルダを開く」
2. `MQL5/Indicators/` に `HeikenAshiSmoothedOverlay.mq5` をコピー
3. MetaEditor でファイルを開き「コンパイル」(F7)
4. ナビゲーターの「インジケーター」からチャートへドラッグ

ポイント:
- **通常ローソク足を前面に表示**（初期値 ON）にすると、HAS が足の背面に描かれます。
  実体の太さを通常の足より太くすると、足の周りに HAS の色が帯のように見えます。
  OFF にすると HAS が足の前面に描かれます。インジケーターを外すと設定は元に戻ります。
- MT5 のインジケーターは半透明にできないため、実体の太さ (1〜5) と前面/背面の切り替えで見やすさを調整してください。
- 確定足で色が変わったときに、アラート / プッシュ通知を出せます。

## TradingView への導入

1. チャート下の「Pine エディタ」を開く
2. `HeikenAshiSmoothedOverlay.pine` の内容を貼り付けて「チャートに追加」

ポイント:
- 色の初期値は透明度 60% なので、通常のローソク足が透けて見えます。設定の「スタイル」で調整できます。
- HAS を足の後ろにしたい場合は、インジケーター名の「…」→「表示順序」→「最背面へ」。
- 「通常ローソク足も HAS の色で塗る」を ON にすると、元の足を HAS のトレンド色で塗れます。
- アラート作成画面で「HAS 陽転」「HAS 陰転」を選べます。

# ハーモニックパターン・スキャナー (MT5)

チャートからハーモニックパターンを自動で探して描画するインジケーターです。

| プラットフォーム | ファイル |
| --- | --- |
| MetaTrader 5 | `mt5/HarmonicPatternScanner.mq5` |

## 機能

- 独自の ZigZag でスイングを検出し、連続する 5点 X-A-B-C-D をフィボナッチ比率で判定
- 対応パターン: Gartley / Bat / Alt Bat / Butterfly / Crab / Deep Crab / Cypher（個別に ON/OFF）
- 完成パターン: 三角形の塗り、各比率、X〜D ラベル、パターン名と精度 (%)、D 点の PRZ、利確目安 (AD の 38.2% / 61.8%)
- 形成中パターン: D 点が未確定のものを破線で表示
- **予測ゾーン (PRZ)**: X-A-B-C がそろった段階で「どこで D が完成するか」を金色の帯で表示
- アラート / プッシュ通知: パターン完成時、価格が予測ゾーンに入った時

## 判定に使う比率

| パターン | AB/XA | BC/AB | CD/BC | D 点 |
| --- | --- | --- | --- | --- |
| Gartley | 0.618 | 0.382–0.886 | 1.13–1.618 | XA の 0.786 |
| Bat | 0.382–0.50 | 0.382–0.886 | 1.618–2.618 | XA の 0.886 |
| Alt Bat | 〜0.382 | 0.382–0.886 | 2.0–3.618 | XA の 1.13 |
| Butterfly | 0.786 | 0.382–0.886 | 1.618–2.618 | XA の 1.27–1.618 |
| Crab | 0.382–0.618 | 0.382–0.886 | 2.24–3.618 | XA の 1.618 |
| Deep Crab | 0.886 | 0.382–0.886 | 2.0–3.618 | XA の 1.618 |
| Cypher | 0.382–0.618 | 1.272–1.414 | — | XC の 0.786 |

各比率に「許容誤差」（初期値 ±5%）を加えて判定します。

## 導入

1. MT5 で「ファイル」→「データフォルダを開く」
2. `MQL5/Indicators/` に `HarmonicPatternScanner.mq5` をコピー
3. MetaEditor で開いて「コンパイル」(F7)
4. ナビゲーターからチャートへドラッグ

## 調整のポイント

- **スイング判定の本数**（初期値 8）: 大きくすると大きな波だけ、小さくすると細かい波も拾います。
- **許容誤差**: 大きくすると検出数が増えますが、精度は下がります。
- スイングは右側に「判定の本数」分の足がそろって確定します。そのため完成パターンは数本遅れて表示されます。それより前の段階は「形成中」と「予測ゾーン」で確認してください。
- バッファ 1（Bullish D）・2（Bearish D）に完成パターンの D 点価格が入るので、EA から `iCustom` で読めます。
