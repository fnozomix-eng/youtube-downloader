# MTF スーパーボリンジャー（マーフィー式）+ アラート — MT5 版

`MTF_SuperBollinger.mq5`（TradingView 版 `tradingview/mtf_super_bollinger.pine` と同等機能）

## インストール
1. MT5 で「ファイル」→「データフォルダを開く」→ `MQL5/Indicators/` に `MTF_SuperBollinger.mq5` をコピー。
2. MetaEditor で開いてコンパイル（F7）。
3. ナビゲーターの「インディケータ」からチャートへドラッグ。

## 既定パラメータ（マーフィー式）
| 項目 | 値 |
|---|---|
| 期間 | 21 |
| バンド | ±1σ / ±2σ / ±3σ |
| 遅行スパン | 終値を21本前（当日含む）に表示 |
| 移動平均 | SMA（EMA に切り替え可） |

## 機能
- **MTF**: バンド1（既定=チャート足）とバンド2（既定=H4）を同時表示。
- **リペイント防止**: 上位足は確定値を使用（OFF で形成中の値をリアルタイム反映）。
- **バンドタッチ** / **実体ブレーク**（「終値で抜け」「実体が完全に外側」）/ **遅行スパンタッチ**。
- 対象ライン（±3σ/±2σ/±1σ/移動平均）を選択可。
- 通知方法: ポップアップ / プッシュ通知（スマホ）/ メール。
  - プッシュ通知は「ツール」→「オプション」→「通知」で MetaQuotes ID を設定してください。

## 補足
- 遅行スパンの線はチャート時間足のみ表示（上位足の遅行スパンは判定のみ）。上位足は上位足確定時に1回通知。
- σ は SMA 基準の母標準偏差（`iStdDev`, TradingView 版と同じ計算）。
- 上位足のデータ読み込み中は表示されないことがあります（自動で再計算します）。

# MTF GMMA + アラート — MT5 版

`MTF_GMMA.mq5`（TradingView 版 `tradingview/mtf_gmma.pine` と同等機能）。インストール方法は上記と同じ。

- 短期群 EMA 3/5/8/10/12/15、長期群 EMA 30/35/40/45/50/60
- GMMA1（既定=チャート足）/ GMMA2（既定=H4）の MTF 表示
- 線の色: 上向き = 緑系グラデーション / 横ばい = 黄色 / 下向き = 赤系グラデーション（色は設定で変更可）
- アラート: 群タッチ / 群の上抜け・下抜け / ゴールデンクロス・デッドクロス（平均線 or 群全体）
- GC / DC は矢印でも表示
- 通知: ポップアップ / プッシュ / メール
