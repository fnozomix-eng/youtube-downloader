# 平均足スムーズド (Heiken Ashi Smoothed) オーバーレイ

通常のローソク足チャートに、平均足スムーズドを重ねて表示するインジケーターです。

| プラットフォーム | ファイル |
| --- | --- |
| MetaTrader 5 | `mt5/HeikenAshiSmoothedOverlay.mq5` |
| TradingView | `tradingview/HeikenAshiSmoothedOverlay.pine` |

## 計算方法 (MT5・TradingView 共通)

1. 価格の始値・高値・安値・終値を 1段目の移動平均で平滑化（初期値: SMMA 6）
2. 平滑化した値から平均足を計算
   - 終値 = (O + H + L + C) / 4
   - 始値 = (前の足の平均足始値 + 前の足の平均足終値) / 2
3. 平均足の 4本値を 2段目の移動平均でさらに平滑化（初期値: LWMA/WMA 2）

初期値は MT4 でよく使われている「Heiken Ashi Smoothed」と同じ設定です。

## MT5 への導入

1. MT5 で「ファイル」→「データフォルダを開く」
2. `MQL5/Indicators/` に `HeikenAshiSmoothedOverlay.mq5` をコピー
3. MetaEditor でファイルを開き「コンパイル」(F7)
4. ナビゲーターの「インジケーター」からチャートへドラッグ

ポイント:
- **通常ローソク足を前面に表示**（初期値 ON）にすると、HAS が足の背面に描かれます。
  実体の太さを通常の足より太くすると、足の周りに HAS の色が帯のように見えます。
  OFF にすると HAS が足の前面に描かれます。インジケーターを外すと設定は元に戻ります。
- MT5 のインジケーターは半透明にできないため、実体の太さ (1〜5) と前面/背面の切り替えで見やすさを調整してください。
- 確定足で色が変わったときに、アラート / プッシュ通知を出せます。

## TradingView への導入

1. チャート下の「Pine エディタ」を開く
2. `HeikenAshiSmoothedOverlay.pine` の内容を貼り付けて「チャートに追加」

ポイント:
- 色の初期値は透明度 60% なので、通常のローソク足が透けて見えます。設定の「スタイル」で調整できます。
- HAS を足の後ろにしたい場合は、インジケーター名の「…」→「表示順序」→「最背面へ」。
- 「通常ローソク足も HAS の色で塗る」を ON にすると、元の足を HAS のトレンド色で塗れます。
- アラート作成画面で「HAS 陽転」「HAS 陰転」を選べます。
