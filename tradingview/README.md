# MTF スーパーボリンジャー（マーフィー式）+ アラート

TradingView 用 Pine Script v6 インジケーター: `mtf_super_bollinger.pine`

## 使い方
1. TradingView の Pine エディタに `mtf_super_bollinger.pine` の内容を貼り付けて「チャートに追加」。
2. アラート作成 → 条件にこのインジケーターを選び **「alert() 関数呼び出しのみ」** を選択（全アラートを1つで受信）。
   個別に受けたい場合は「バンド1 タッチ」などの alertcondition を選択。

## 既定パラメータ（マーフィー式）
| 項目 | 値 |
|---|---|
| 期間 | 21 |
| バンド | ±1σ / ±2σ / ±3σ |
| 遅行スパン | 終値を21本前（当日含む）に表示 |
| 移動平均 | SMA（EMA に切り替え可） |

## 機能
- **MTF**: バンド1（既定=チャート足）とバンド2（既定=4時間足）を同時表示。時間足は自由に変更可。
- **リペイント防止**: 上位足は確定値を使用（OFF で形成中の値）。
- **バンドタッチ**: チャート足の高値〜安値がラインに触れたとき。
- **実体ブレーク**: 「終値で抜け」または「実体が完全に外側」を選択可。上抜け/下抜けを通知。
- **遅行スパンタッチ**: 各時間足の遅行スパン（終値）が、21本前のバンド/移動平均に到達・跨いだとき。上位足は上位足確定時に1回だけ通知。
- 対象ライン（±3σ/±2σ/±1σ/移動平均）はアラート設定で選択。

> 遅行スパンの線表示はチャート時間足のみ（上位足の遅行スパンはアラート判定のみ）。
